# CentOS Stream 9 Installation

## Objective
Install CentOS Stream 9 manually on a VirtualBox virtual machine to understand OS-level setup before introducing automation.

---

## ISO Image
- **OS:** CentOS Stream 9
- **Type:** Enterprise Linux distribution
- **Installation Method:** ISO-based manual installation

---

## VM Configuration (Before Installation)
The virtual machine was configured manually with:
- Allocated CPU cores
- Assigned RAM
- Virtual hard disk created
- ISO attached as boot media

Exact values may vary depending on host capacity, but the focus is on understanding the process rather than optimization.

---

## Installation Flow (High Level)
1. Created a new VM in Oracle VirtualBox
2. Attached the CentOS Stream 9 ISO
3. Booted the VM from ISO
4. Selected installation options
5. Created a user account
6. Completed installation and rebooted

---

## Why Manual Installation Matters
Manual installation helps understand:
- Boot process
- Disk setup
- User creation
- OS initialization

This knowledge is critical when troubleshooting automated or cloud-based installations later.
