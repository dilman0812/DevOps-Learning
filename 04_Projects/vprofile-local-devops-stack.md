# VProfile Local DevOps Stack

This is a completed hands-on DevOps project implemented as part of my
DevOps learning journey.

The project focuses on setting up and running a multi-tier application
locally using DevOps tools and infrastructure best practices.

## Project Repository
🔗 https://github.com/dilman0812/vprofile-local-devops-stack

## Architecture Overview
- Multi-VM setup using Vagrant
- Separate Linux servers for application components
- Private networking between services

## DevOps Concepts Practiced
- Virtual machine provisioning with Vagrant
- Linux server configuration and service management
- Multi-service application setup
- Inter-service networking and connectivity
- Debugging configuration and runtime issues
- Infrastructure reproducibility

## Key Learnings
- Understanding real-world service dependencies
- Troubleshooting startup and connectivity failures
- Managing configuration files and environment variables
- Applying DevOps fundamentals in a local environment
