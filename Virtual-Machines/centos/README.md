# CentOS Virtual Machine

## Overview
This directory documents the setup and management of a **CentOS Stream 9 virtual machine** as part of my DevOps learning.

CentOS is widely used in enterprise and server environments. Learning it at the VM level provides a strong foundation for cloud infrastructure, automation, and production systems.

---

## VM Details

| Item | Value |
|----|------|
| VM Name | `centosvm` |
| OS | CentOS Stream 9 |
| Hypervisor | Oracle VirtualBox |

---

## What Is Covered
This CentOS VM documentation includes:
- Manual OS installation
- VM networking configuration
- IP address discovery
- Remote access using SSH

All steps are performed **manually**, following the DevOps principle of understanding before automation.

---

## Why CentOS for DevOps
CentOS Stream is chosen because:
- It is closely aligned with RHEL
- Commonly used in enterprise servers
- Widely seen in cloud and production workloads
- Helps build production-ready Linux skills
